<objective>
Stop raw post counts from reading as public opinion. Every post gets a per-source normalized
`reach_score` (0-1), the 15-minute rollups carry reach-weighted sentiment (`reach_pos/neu/neg`),
the brief shows the reach-weighted headline with the raw split beside it, and a lane toggle
(All / Social / Media and analyst) on the brief and topic pages filters every number through the
`lane` URL param. Contract gaps filled here: trust thresholds live in worker code
(`TRUST_DEFAULTS`, not in `AppConfig`); `packages/core/src/api-types.ts` gains additive `reach`
fields; the filter bar, KPI row and topics table built in 04-02 receive mount-only edits.
</objective>

  <name>Task 1: Reach scoring and trust defaults</name>
  <files>apps/worker/src/trust/config.ts, apps/worker/src/trust/config.test.ts, apps/worker/src/trust/reach.ts, apps/worker/src/trust/reach.test.ts, apps/worker/src/trust/reach.int.test.ts</files>
  <action>Tests first (Vitest), then the code.
  `trust/config.ts` exports zod `TrustConfig` and `TRUST_DEFAULTS`:
  reach = { percentile: 0.95, lookbackDays: 7, mediaOutletWeight: 0.6, floor: 0.05, unknownScore: 0.25,
  minSamplesForPercentile: 20, defaultP95Log: { x_api: 5, x_apify: 5, apify_linkedin: 4, apify_instagram: 4,
  youtube: 5, reddit: 3 }, fullRescoreEveryMin: 60 }; coordination = { nearDupMinAuthors: 5, nearDupWindowMin: 60,
  burstMultiplier: 4, burstMinItems: 10, top5ShareThreshold: 0.4, top5MinItems: 30 } (06-02 reads the second
  block). `resolveTrustConfig(appConfig: unknown): TrustConfig` deep-merges an optional `appConfig.trust`
  over the defaults and falls back to the defaults when the parse fails. Do not edit the core config schema.
  `trust/reach.ts` exports pure functions:
  - `mainMetric(sourceKey, reachRaw, authorFollowers?): number | undefined`. X (both keys) and apify_linkedin use
    followers (`reachRaw.followers ?? authorFollowers`), youtube uses views, reddit uses upvotes, apify_instagram
    uses likes. Every other source returns undefined.
  - `percentile(values: number[], p: number): number` (linear interpolation; returns 0 for an empty array).
  - `computeReachScore({lane, sourceKey, reachRaw, authorFollowers}, p95Log, cfg): number`. A media-lane post
    gets `cfg.mediaOutletWeight`. A missing metric gets `cfg.unknownScore`. Otherwise the score is
    clamp(log10(1+m) / p95Log, cfg.floor, 1), and p95Log <= 0 is treated as 1.
  - `p95LogBySource(rows, cfg): Record<SourceKey, number>` uses the computed percentile when the source has at
    least minSamplesForPercentile social rows with a metric, otherwise `defaultP95Log[source]` (or 4 when none).
  The DB function is `refreshReachScores(db, now: Date, cfg, opts: {full: boolean}): Promise<{updated: number}>`.
  With full=true it selects every post with published_at inside lookbackDays (id, source_key, lane, reach_raw,
  authors.followers through a LEFT JOIN, used only for this aggregate), recomputes p95 per source, caches it in
  module state with the computation time, and rescores all of those posts. With full=false it scores only rows
  where reach_score IS NULL, using the cached p95 (and runs a full pass when there is no cache). Write the scores
  with `UPDATE posts SET reach_score = v.s FROM (VALUES ...) v(id, s) WHERE posts.id = v.id` in chunks of 500.
  Export `shouldFullRescore(lastFullAt: Date | null, now, cfg)`.
  Unit tests: a 10k-follower X post scores about 0.8 when p95Log = 5; 0 followers gives the floor; a missing metric
  gives 0.25; a media post gives 0.6 whatever its metric; a score never exceeds 1; with fewer than 20 samples
  the default p95 is used; the percentile of [1..100] at 0.95 is 95.05.
  The integration test (`reach.int.test.ts`, DATABASE_URL_TEST, the 01-02 harness) inserts posts across x_api,
  reddit and news_rss. One full refresh sets every reach_score. A second, incremental refresh touches only
  newly inserted rows.</action>
  <verify>corepack pnpm --filter @jio/worker exec vitest run src/trust/ ; corepack pnpm --filter @jio/worker typecheck</verify>
  <done>All trust tests pass. After a full refresh, no post in the test DB has a NULL reach_score. Every score is in [0.05, 1], and every media post has exactly 0.6.</done>
