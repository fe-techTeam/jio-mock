  missing a column, and returns a header-index map.
  `pickColumn` prefers an exact 'NII' header over 'bNII'/'sNII' and falls back to 'HNI'. It maps 'RII' and 'Retail' to retail. For GMP it picks 'GMP' or 'IPO GMP' or 'GMP (₹)' and never 'GMP %', 'Est. Listing' or 'Kostak'.

  `parseObservedAt` reads 'Last Updated: 16-Oct-2026 14:05' and '16 Oct 2026, 2:05 PM' as IST (+05:30) and falls back to now.

  Implement portal-shared.ts:
  - `ISSUER_ROW_PATTERN = /\bjio\s*platforms?\b|\breliance\s+jio\b/i` and `ISSUER_EXCLUDE_PATTERN = /jio\s*financial|\bjfsl?\b/i`.
  - `extractGmp($, ctx): NormalizedMarketPoint[]`: required headers are a name column /ipo|name|company/ and /gmp/. If no table matches, throw `SourceParseError('<key>: GMP table not found')`.

  - `extractSubscription($, ctx)`: required headers /qib/, /nii|hni/, /retail|rii/ and /total|overall/. It returns up to 4 points; a null cell skips that series.
    A missing table throws SourceParseError('<key>: subscription table not found').
  - `extractNewsLinks($, baseUrl, portal, matcher, now): NormalizedPost[]`: takes anchors with text of at least 25 chars that pass the @jio/core keyword matcher, resolves absolute URLs and dedupes by href.

  - `createPortalAdapter(spec: { key; name; domain; gmpUrl; subscriptionUrl; fixtureFile; overrides? }, deps?)`.
    In fixture mode it parses `readFixtureText(spec.fixtureFile)` once for both tables and the news links. In live mode it makes 2 GETs with UA `jio-ipo-analysis/0.1 (+internal research)` and ctx.signal.
    Non-2xx throws `HTTP <status> <url>`; 429 throws RateLimitedError(now + 30 min). costUsd is 0. sourceUrl is the page the value came from.</action>
