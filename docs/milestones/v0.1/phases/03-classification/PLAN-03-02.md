<objective>
Stage two of the classifier: a `Classifier` that labels triaged posts with topic, sentiment, mentioned
entities, confidence and a one-line English gloss. The Anthropic implementation (CLASSIFIER_MODEL,
default `claude-haiku-5-5`) sends batches of 20-50 posts as wrapped untrusted data and gets
schema-validated JSON back. Few-shot examples come from dashboard corrections. The deterministic stub
runs whenever ANTHROPIC_API_KEY is empty, which includes every test. Low confidence, unknown topics and
items that fail validation all become `topicSlug: 'unclassified'` with confidence 'low'.

This plan has no database access. 03-03 injects the content-hash cache and the few-shot loader. Contract
additions defined here: the `Classifier` gains readonly `model` and `promptVersion`, and
`createClassifier`, `FewShotExample`, `ClassifyItem` and `ClassificationCache` are new. If @jio/core does
not export `TopicDef` (check SUMMARY-01-01), define `TopicDef = { slug; name; description;
examplePhrases: string[]; kind: TopicKind }` in classifier.ts. The worker gets `@anthropic-ai/sdk` and
`zod@3` (if not already present). That edits apps/worker/package.json and the lockfile, which are
outside the ROADMAP Owns column. 03-01 adds no dependencies, so the wave stays disjoint.
</objective>
