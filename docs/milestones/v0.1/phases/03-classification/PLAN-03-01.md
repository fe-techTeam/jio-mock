<objective>
Stage one of the two-stage classifier: every ingested post is triaged before any LLM sees it. Triage
detects the language (en, hinglish, hi, gu, other), runs the @jio/core keyword matcher (bare 'jio'
never matches alone; negative terms such as JioStar or Jio Financial Services drop the post), stores a
content hash, embeds relevant posts (Voyage `voyage-multilingual-2`, 1024 dims, or a deterministic
hashing stub) and assigns near-duplicate clusters at cosine >= 0.95. 03-03 calls `triagePosts` from the
classify-batch job and 06-02 reads `near_dup_cluster_id` for coordination flags.

Contract notes (filled here, CONTRACTS.md not edited): CONTRACTS names the embedding stub
`classify/stub.ts`, but ROADMAP gives that file to the classifier stub, so the embedding stub is
`classify/embed-stub.ts`. Posts carry no "relevant" flag, so triage marks state with existing columns:
`lang IS NULL` = untriaged; `matched_terms = '{}'` with `embedding IS NULL` = dropped as irrelevant.
This plan adds no npm dependencies (Voyage is called with plain `fetch`; SQL goes through the
postgres-js `sql` client returned by `createDb`).
</objective>

  `embed-stub.ts`: `HashingEmbedder` (model 'hash-stub-v1'): tokenize `normalizeForHash(text)` on
  `[\p{L}\p{N}]+`, take unigrams and adjacent bigrams, FNV-1a 32-bit hash each, index = h % 1024,

  Tests: 1024 dims; norm 1 (+-1e-9); deterministic across calls; a tweet and its copy with a different

  `Authorization: Bearer <key>`, chunks of at most 64 texts, inputs truncated to 8,000 chars, results
  re-ordered by `data[].index`. Retry 429 and 5xx up to 3 times with 500 ms x 2^n backoff (sleep is
  injectable for tests); 4xx other than 429 throws `EmbedError` with status and body. costUsd =
